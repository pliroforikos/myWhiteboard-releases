## 1. Εισαγωγή & Φιλοσοφία Εφαρμογής

Το **myWhiteboard** είναι μια σύγχρονη, αυτόνομη εκπαιδευτική εφαρμογή ψηφιακού πίνακα και σχεδίασης πάνω από την επιφάνεια εργασίας (Desktop Annotation). Εμπνευσμένο από την απλότητα και την εργονομία του **OpenBoard**, αναπτύχθηκε με έμφαση στις απαιτήσεις της σύγχρονης διδασκαλίας και ιδιαίτερα των μαθημάτων **Πληροφορικής (ΑΕΠΠ / ΓΛΩΣΣΑ / Python / Αντικειμενοστραφής Προγραμματισμός)**.

### Κύριοι Πυλώνες Σχεδιασμού:
- **Άμεση Ετοιμότητα (Default Mouse Mode):** Κατά την εκκίνηση, το ποντίκι παραμένει πλήρως λειτουργικό με διαπερατότητα κλικ (*click-through*), ώστε να μπορείτε να εργάζεστε στα υπάρχοντα προγράμματά σας (IDE, browser, PDF, διαφάνειες) χωρίς εμπόδια.
- **Εκπαιδευτική Εξειδίκευση:** Ενσωματώνει έτοιμες διαδραστικές δομές δεδομένων (Πίνακες, Στοίβες, Ουρές, Λίστες, Δένδρα, Γράφους) και διαγράμματα OOP ακριβώς όπως περιγράφονται στο σχολικό βιβλίο.
- **Αυτονομία (100% Offline):** Όλες οι γραμματοσειρές (Google Roboto με πλήρη ελληνική υποστήριξη), τα εικονίδια και τα εργαλεία λειτουργούν τοπικά χωρίς ανάγκη σύνδεσης στο διαδίκτυο.
- **Κορυφαία Ευκρίνεια & Αντίθεση (WCAG AAA):** Πλήρης υποστήριξη Dark και Light mode με προσεγμένους χρωματικούς συνδυασμούς για καθαρή προβολή σε οθόνες και βιντεοπροβολείς τάξης.

## 2. Εγκατάσταση & Εκτέλεση

Η εφαρμογή διατίθεται σε δύο μορφές για λειτουργικά συστήματα **Windows** (και υποστηρίζει μεταγλώττιση για Linux):

### Α. Αυτόνομη Φορητή Έκδοση (Portable Executable)
- **Αρχείο:** `myWhiteboard-Portable-1.1.2.exe`
- **Τρόπος Χρήσης:** Δεν απαιτεί καμία απολύτως εγκατάσταση ή δικαιώματα διαχειριστή (Admin). Μπορείτε να το αντιγράψετε σε ένα USB flash drive και να το εκτελέσετε άμεσα σε οποιονδήποτε υπολογιστή τάξης ή εργαστηρίου.

### Β. Τυπική Εγκατάσταση Windows (Setup Installer)
- **Αρχείο:** `myWhiteboard-Setup-1.1.2.exe`
- **Τρόπος Χρήσης:** Κλασικός οδηγός εγκατάστασης NSIS. Επιτρέπει την επιλογή φακέλου εγκατάστασης, δημιουργεί συντομεύσεις στην Επιφάνεια Εργασίας και στο μενού Έναρξη, και περιλαμβάνει πλήρες πρόγραμμα απεγκατάστασης.

## 3. Περιβάλλον Εργασίας & Παλέτα Εργαλείων (Dock)

Η εργαλειοθήκη του myWhiteboard έχει σχεδιαστεί ώστε να καταλαμβάνει τον ελάχιστο δυνατό χώρο, προσφέροντας παράλληλα άμεση πρόσβαση σε κάθε εργαλείο.

```
+-------------------------------------------------------+
|  [::] Λαβή Μετακίνησης (Drag Handle)                 |
|  [🖱️] Ποντίκι / Click-Through Mode (M)                 |
|  [  ] Ένδειξη Τρέχοντος Εργαλείου & Χρώματος          |
|  ---------------------------------------------------  |
|  [🖊️] Μολύβι (P) ▾                                    |
|  [🧹] Σβήστρα (E) ▾                                   |
|  [🖍️] Μαρκαδόρος Υπογράμμισης (H) ▾                  |
|  [📏] Ευθεία Γραμμή                                   |
|  [➡️] Βελάκι Κατεύθυνσης                              |
|  [📐] Γεωμετρικά Σχήματα (S) ▾                        |
|  [🔤] Εργαλείο Κειμένου (T) ▾                         |
|  [▦ ] Δομές Δεδομένων & Πίνακες (G) ▾                 |
|  [🏛️] Αντικειμενοστραφής Προγραμματισμός (C) ▾       |
|  ---------------------------------------------------  |
|  [🖥️] Εναλλαγή Φόντου & Θέματος (D) ▾                  |
|  [↶][↷] Αναίρεση (Ctrl+Z) / Επανάληψη (Ctrl+Y)        |
|  [🔄][☀️/🌙][ℹ️] Προσανατολισμός / Θέμα / Info        |
|  [ _ ][ X ] Ελαχιστοποίηση / Έξοδος                   |
|  [::] Κάτω Λαβή Μετακίνησης                           |
+-------------------------------------------------------+
```

### Βασικές Λειτουργίες Εργαλειοθήκης:
- **Ελεύθερη Μετακίνηση (Drag & Drop):** Πατήστε και σύρετε την εργαλειοθήκη από την επάνω ή την κάτω διάστικτη λαβή σε οποιοδήποτε σημείο της οθόνης.
- **Εναλλαγή Προσανατολισμού (Κάθετη ⇄ Οριζόντια):**
  - Πατήστε το κουμπί `🔄` ή πατήστε το πλήκτρο **`O`**.
  - **Κάθετη Διάταξη:** Τα αναδυόμενα μενού (flyouts) ανοίγουν προς τα δεξιά.
  - **Οριζόντια Διάταξη:** Τα υπομενού **αναπτύσσονται έξυπνα προς τα κάτω** (ή προς τα πάνω εάν η εργαλειοθήκη βρίσκεται στο κάτω μέρος της οθόνης), παραμένοντας πλήρως ορατά ακόμα και σε μικρές αναλύσεις.
- **Κουτί Ένδειξης Κατάστασης (Status Box):** Εμφανίζει ανά πάσα στιγμή το ενεργό χρώμα και το μέγεθος του επιλεγμένου εργαλείου.

## 4. Θέματα Εμφάνισης: Dark Mode & Light Mode

Το myWhiteboard διαθέτει δύο ολοκληρωμένα θέματα εμφάνισης, προσαρμοσμένα στις συνθήκες φωτισμού της αίθουσας:

### 🌓 Εναλλαγή Θέματος:
1. **Από το Dock:** Πατήστε το κουμπί `☀️`/`🌙` (δίπλα στο Info).
2. **Μέσω Πληκτρολογίου:** Πατήστε **`Shift + T`** ή **`F6`**.
3. **Από το Μενού Φόντου:** Ανοίξτε το μενού φόντου (`D`) και επιλέξτε *Σκοτεινό (Dark)* ή *Φωτεινό (Light)*.

### Χαρακτηριστικά Θεμάτων:
- **Σκοτεινό Θέμα (Dark Mode):**
  - Βαθύ γραφίτη/slate dock (`#1e293b` / `#0f172a`) με φωτεινά εικονίδια.
  - Μειώνει την καταπόνηση των ματιών σε συνθήκες χαμηλού φωτισμού ή κατά τη χρήση βιντεοπροβολέα.
- **Φωτεινό Θέμα (Light Mode):**
  - Μαργαριταρένιο λευκό dock (`#ffffff` / `#f8fafc`) με έντονο περίγραμμα (`#cbd5e1`).
  - **Απόλυτη ευκρίνεια γραμμάτων και εικονιδίων (`#0f172a`)** σε όλα τα μενού, κουμπιά και παράθυρα διαλόγου, με αναλογία αντίθεσης που υπερβαίνει το πρότυπο WCAG AAA (> 14:1).
- **Αυτόματη Απομνημόνευση:** Το θέμα που επιλέγετε διατηρείται αυτόματα για τις επόμενες συνεδρίες.

## 5. Επιφάνειες Σχεδίασης & Φόντα Πίνακα (Background Modes)

Πατώντας το κουμπί φόντου (ή το πλήκτρο **`D`**), έχετε στη διάθεσή σας 7 διαφορετικές επιφάνειες εργασίας:

| # | Τύπος Φόντου | Περιγραφή | Ιδανικό για |
|---|---|---|---|
| **1** | **Επιφάνεια Εργασίας** | 100% διαφανής καμβάς με διαπερατότητα κλικ. | Σχολιασμό σε πραγματικό χρόνο πάνω από προγράμματα, web, PDF. |
| **2** | **Λευκός Πίνακας** | Καθαρός λευκός ασπροπίνακας. | Κλασική διδασκαλία και επίλυση ασκήσεων. |
| **3** | **Καντριγιέ (Τετράδιο)** | Λευκό φόντο με απαλό γκρι πλέγμα ($30\times 30\text{ px}$). | Μαθηματικά, σχεδίαση σχημάτων, γραφήματα και πίνακες. |
| **4** | **Ριγέ (Γραμμές)** | Λευκό φόντο με οριζόντιες γραμμές και κόκκινο περιθώριο. | Σημειώσεις κειμένου, εκθέσεις και γραφή. |
| **5** | **Μαυροπίνακας (Chalkboard)** | Σκούρος σχολικός πίνακας κιμωλίας. | Παραδοσιακό μάθημα με κιμωλία, ξεκούραστο για τα μάτια. |
| **6** | **Σκοτεινό Καντριγιέ** | Σκούρο φόντο με διακριτικό κυανό πλέγμα. | Πληροφορική, προγραμματισμό, δένδρα και γράφους. |
| **7** | **Σκοτεινό Ριγέ** | Σκούρο φόντο με απαλές οριζόντιες γραμμές. | Ευανάγνωστες σημειώσεις σε σκοτεινό περιβάλλον. |

> [!TIP]
> **Αυτόματη Προσαρμογή Αντίθεσης Μολυβιού:** Εάν σχεδιάζετε με μαύρο μολύβι και επιλέξετε Μαυροπίνακα (Darkboard), η εφαρμογή αλλάζει αυτόματα το μολύβι σε λευκό. Αντίστροφα, κατά τη μετάβαση σε Λευκό Πίνακα, το λευκό μολύβι αλλάζει αυτόματα σε μαύρο, διασφαλίζοντας ότι οι γραμμές σας είναι πάντοτε άμεσα ορατές!

## 6. Βασικά Εργαλεία Σχεδίασης & Γραφής

### 🖱️ Ποντίκι / Λειτουργία Επιλογής (Πλήκτρο `M`)
- Επιτρέπει τη διαπερατότητα κλικ στην επιφάνεια εργασίας (Desktop Mode).
- Όταν πλησιάσετε ένα δημιουργημένο αντικείμενο (πίνακα, διάγραμμα, σχήμα), αποκρίνεται άμεσα για επιλογή, μετακίνηση, αυξομείωση ή διαγραφή.

### 🖊️ Μολύβι (Πλήκτρο `P`)
- **3 Προκαθορισμένα Πάχη:** Λεπτό (3px), Μεσαίο (7px), Παχύ (15px).
- **Παλέτα Χρωμάτων:** 9 βασικά χρώματα (Μαύρο, Άσπρο, Κόκκινο, Σκούρο Μπλε, Μπλε, Πράσινο, Κίτρινο, Πορτοκαλί, Μωβ) συν πλήρης επιλογέας προσαρμοσμένου χρώματος (Color Picker).
- **Εξομάλυνση Bezier:** Αυτόματη εξομάλυνση γραμμής για φυσική, καλλιγραφική αίσθηση γραφής χωρίς τεθλασμένες ατέλειες.

### 🧹 Σβήστρα (Πλήκτρο `E`)
- **3 Μεγέθη Σβήστρας:** Μικρή (20px), Μεσαία (45px), Μεγάλη (85px).
- **Δυναμικός Κυκλικός Κέρσορας:** Απεικονίζει στην οθόνη την ακριβή διάμετρο της επιφάνειας που σβήνεται.
- **Κουμπί «Καθαρισμός Όλων»:** Σβήνει ακαριαία όλες τις ελεύθερες γραμμές του καμβά (διατηρώντας τα αντικείμενα πινάκων και κειμένων).

### 🖍️ Μαρκαδόρος Υπογράμμισης (Highlighter - Πλήκτρο `H`)
- **Ημιδιαφανής Γραφή:** Τονίζει λέξεις ή σχήματα χωρίς να επικαλύπτει το υποκείμενο περιεχόμενο.
- **3 Πάχη:** 16px, 28px, 48px.
- **5 Φωσφοριζέ Χρώματα:** Κίτρινο, Πράσινο, Γαλάζιο, Ροζ, Πορτοκαλί.

### 📏 Ευθεία Γραμμή & ➡️ Βελάκι Κατεύθυνσης
- Σχεδιάζονται ελεύθερα με σύρσιμο προς οποιαδήποτε κατεύθυνση.
- Καθαρή γεωμετρία χωρίς ενσωματωμένο κείμενο, ιδανική για βέλη ροής, άξονες και υπογραμμίσεις.

### 📐 Γεωμετρικά Σχήματα με Dynamic Auto-Fit Text (Πλήκτρο `S`)
- **Διαθέσιμα Σχήματα:** Ορθογώνιο, Πλάγιο Παραλληλόγραμμο, Κύκλος, Έλλειψη, Ρόμβος.
- **Ενσωμάτωση Κειμένου:** Κάντε διπλό κλικ σε οποιοδήποτε σχήμα και πληκτρολογήστε ελεύθερα.
- **Αυτόματη Αναλογική Προσαρμογή (Auto-Fit Scaling):**
  - Καθώς γράφετε, τα γράμματα **μικραίνουν αυτόματα** ώστε το κείμενο να παραμένει πάντα μέσα στα όρια του σχήματος.
  - Αν μεγαλώσετε το σχήμα από τις λαβές του, τα γράμματα **μεγαλώνουν αναλογικά**!
- **8 Λαβές Αυξομείωσης Μεγέθους:** Σύρετε οποιαδήποτε πλευρά ή γωνία για άμεση αλλαγή διαστάσεων.
- **Έλεγχος Χρωμάτων:** Επιλογή χρώματος περιγράμματος, γεμίσματος (με διαφάνεια) και χρώματος γραμματοσειράς.

### 🔤 Εργαλείο Κειμένου & Sticky Notes (Πλήκτρο `T`)
- **Διαφανές εξ ορισμού:** Το κείμενο εντάσσεται φυσικά στην οθόνη χωρίς αντιαισθητικά πλαίσια.
- **Σημειώσεις Sticky Notes:** Δυνατότητα προσθήκης παστέλ φόντου (Κίτρινο, Γαλάζιο, Πράσινο, Σκούρο) με ένα κλικ.
- **Μέγεθος Γραμματοσειράς:** Επιλογή από 18px έως 48px με υποστήριξη πολυτονικού και τόνων.

### ↶ Αναίρεση (Undo) & ↷ Επανάληψη (Redo)
- Πλήρες ιστορικό ενεργειών με τα κουμπιά του dock ή τις συντομεύσεις **`Ctrl + Z`** και **`Ctrl + Y`**.

## 7. Δομές Δεδομένων & Αλγόριθμοι (Data Structures)

Πατώντας το πλήκτρο **`G`** (ή το εικονίδιο πίνακα στην εργαλειοθήκη), ανοίγει το εξειδικευμένο υπομενού με 6 βασικές δομές δεδομένων:

### 🔍 Γενική Δυνατότητα: Αυξομείωση Μεγέθους 5 Επιπέδων (`A−` / `A+`)
Στην κεφαλίδα **κάθε δομής** υπάρχουν κουμπιά κλιμάκωσης:
- **5 Διαβαθμίσεις:** `1/5 (XS)`, `2/5 (S)`, `3/5 (M - Προεπιλογή)`, `4/5 (L)`, `5/5 (XL)`.
- Αυξομειώνονται ταυτόχρονα τα κελιά, τα γράμματα, οι δείκτες (`[i]`, `front`, `rear`, `top`), οι συνδέσεις και τα περιγράμματα!

---

### ▦ 1. Πίνακες (Arrays 1D & 2D)
- **Διαστάσεις:** Επιλογή γραμμών και στηλών από $1\times 1$ έως $15\times 15$ μέσω διαδραστικού preview matrix ή βημάτων.
- **8 Λαβές Μεγέθους:** Σύρετε οποιαδήποτε γωνία ή πλευρά για ελεύθερη αλλαγή διαστάσεων.
- **Δείκτες Γραμμών & Στηλών (`[0/1]`):**
  - `none`: Χωρίς δείκτες.
  - `0-based`: Αρίθμηση από $0$ (C, C++, Python, Java).
  - `1-based`: Αρίθμηση από $1$ (ΓΛΩΣΣΑ, MATLAB).
- **Τυχαίο Γέμισμα Δεδομένων (Κουμπί `🎲`):**
  - Ακέραιοι αριθμοί με ρυθμιζόμενο εύρος (π.χ. $1-50$, $1-100$, δυαδικοί $0/1$).
  - Πραγματικοί αριθμοί με 1 ή 2 δεκαδικά ψηφία (π.χ. $0.0-10.0$).
  - Ελληνικά Ονόματα (βάση 60+ ονομάτων για ασκήσεις ταξινόμησης/αναζήτησης).
  - Επιλογές 1, 2 ή 3 κειμένων (π.χ. `Α`/`Γ`, `Αληθής`/`Ψευδής`, `Θετικός`/`Αρνητικός`).
- **Τόνιση Διαγωνίων σε Τετραγωνικούς Πίνακες (Κουμπί `⤢`):**
  - 1ο κλικ: Κύρια Διαγώνιος (`i == j`) με απαλό χρυσό/κεχριμπαρί.
  - 2ο κλικ: Δευτερεύουσα Διαγώνιος (`i + j == N + 1`) με απαλό μωβ.
  - 3ο κλικ: Ταυτόχρονη επισήμανση και των δύο διαγωνίων με ειδικό χρώμα τομής.
  - 4ο κλικ: Απενεργοποίηση.
- **Τόνιση Γραμμών & Στηλών:** Κάντε κλικ στην εξωτερική ετικέτα οποιασδήποτε γραμμής ή στήλης για να τονιστεί με διακριτικό παστέλ χρώμα.

---

### 🥞 2. Στοίβες (Stacks - LIFO)
- **Μορφές Εμφάνισης:** Κλασική κατακόρυφη στοίβα (LIFO Container) ή υλοποίηση με μονοδιάστατο πίνακα `STACK[N]`.
- **Χωρητικότητα ($N$):** Ρυθμιζόμενη από 2 έως 12 θέσεις.
- **Λειτουργίες:**
  - `Push`: Εισαγωγή στοιχείου στην κορυφή με αυτόματο έλεγχο υπερχείλισης (*Overflow*).
  - `Pop`: Εξαγωγή στοιχείου από την κορυφή με αυτόματο έλεγχο υποχείλισης (*Underflow*).
  - Δείκτης `top` που ακολουθεί δυναμικά την κορυφή.

---

### 🚶‍♂️ 3. Ουρές (Queues - FIFO)
- **Τύποι Λειτουργίας:**
  - **Γραμμική Ουρά (Σχολικό Βιβλίο ΓΛΩΣΣΑΣ):** Ο δείκτης `rear` προχωρά δεξιά στην εισαγωγή, ο δείκτης `front` προχωρά δεξιά στην εξαγωγή. **Όταν `front > rear`, η ουρά αδειάζει αυτόματα και οι δείκτες μηδενίζονται στο 0!**
  - **Κυκλική / Μετατόπιση:** Τα στοιχεία μετατοπίζονται αυτόματα προς τα αριστερά σε κάθε εξαγωγή.
- **Μορφές Εμφάνισης:** Κλασικός οριζόντιος αγωγός ή πίνακας `QUEUE[N]`.

---

### 🔗 4. Συνδεδεμένες Λίστες (Linked Lists)
- **Κόμβοι:** Κάθε κόμβος αποτελείται από το τμήμα δεδομένων (`Data`) και το δείκτη επόμενου (`Next • ➔`).
- **Δείκτες:** Εμφάνιση δείκτη κεφαλής `HEAD ➔` και τελικού δείκτη `NULL (⏚)`.
- **Λειτουργίες:**
  - Εισαγωγή στην αρχή (Head) ή στο τέλος (Tail).
  - **Διαγραφή οποιουδήποτε κόμβου:** Κάντε κλικ στο κόκκινο κουμπί `✕` πάνω από τον κόμβο για άμεση διαγραφή και αυτόματη επανασύνδεση των δεικτών!

---

### 🌳 5. Δένδρα (Binary Trees & BST)
- **Έτοιμα Πρότυπα:**
  - Δυαδικό Δένδρο Αναζήτησης (BST με τιμές 48, 25, 65, 12, 38, 58, 79).
  - Αριθμητική Έκφραση: $(a + b) \times c$.
  - Δένδρο Απόφασης & Οργανόγραμμα.
- **Διαδραστική Επεξεργασία:** Προσθήκη αριστερού (`+L`) ή δεξιού (`+R`) παιδιού σε οποιονδήποτε κόμβο, ελεύθερο σύρσιμο κόμβων με αυτόματη δυναμική επανασχεδίαση των κλαδιών.

  - Κοινωνικό Δίκτυο (Social Network Graph).

## 8. Αντικειμενοστραφής Προγραμματισμός (OOP Diagrams)

Πατώντας το πλήκτρο **`C`** (ή το εικονίδιο με το κτίριο/κλάση στο dock), ανοίγει η σουίτα διαγραμμάτων Αντικειμενοστραφούς Προγραμματισμού, σχεδιασμένη σύμφωνα με το σχολικό βιβλίο ([`book.pdf`](./book.pdf)) και τα διαγωνίσματα ([`test.pdf`](./test.pdf)):

```
+-------------------------------------------------------+
|  Διάγραμμα Κλάσεων / Αντικειμένων                     |
|                                                       |
|   +-----------------------+                           |
|   | Μαθητής (Γιώργος)     |  [+Ιδ] [+Μεθ] [✕]         |
|   +-----------------------+                           |
|   | Όνομα: Γιώργος        |  (Τμήμα Ιδιοτήτων)        |
|   | ΑΜ: 1042              |                           |
|   - - - - - - - - - - - - -  (Στικτή Γραμμή Βιβλίου)  |
|   | Μελετά()              |  (Τμήμα Μεθόδων)          |
|   | ΕπιλύειΑσκήσεις()     |                           |
|   +-----------------------+                           |
|              |                                        |
|              | ⮉ (Σύμβολο Γενίκευσης UML)            |
|              v                                        |
|   +-----------------------+                           |
|   | Άτομο (Υπερκλάση)     |                           |
|   +-----------------------+                           |
+-------------------------------------------------------+
```

### Α. Τα 3 Είδη Διαγραμμάτων:
1. **Διάγραμμα Αντικειμένων (Object Diagram - Εικ. 4.2):**
   - Επικεφαλίδα: `Όνομα (Κλάση)` (π.χ. `Μαθητής (Γιώργος)`).
   - Τμήμα Ιδιοτήτων: Με συγκεκριμένες τιμές (π.χ. `Όνομα: Γιώργος`, `ΑΜ: 1042`).
   - Στικτή διαχωριστική γραμμή & τμήμα μεθόδων.
2. **Διάγραμμα Κλάσεων (Class Diagram - Εικ. 4.5):**
   - Επικεφαλίδα: Όνομα κλάσης.
   - Σκιασμένο φόντο ιδιοτήτων (`#e9eff5`) χωρίς τιμές.
   - Στικτή γραμμή & τμήμα μεθόδων σε λευκό φόντο.
3. **Ιεραρχία Κληρονομικότητας (Inheritance Hierarchy - Εικ. 4.10):**
   - Υπερκλάση στην κορυφή.
   - **Επίσημο σύμβολο γενίκευσης UML:** Κενό/λευκό ισόπλευρο τρίγωνο `⮉` με φορά προς την υπερκλάση.
   - Οριζόντια διακλάδωση και εξειδικευμένες υποκλάσεις.

### Β. Πλήρες Σύστημα CRUD σε Κάθε Στοιχείο:
- **Προσθήκη Καρτών με Αναδυόμενο Μενού (`+ Κλάση ▾` / `+ Αντικείμενο ▾`):**
  - Κάνοντας κλικ, εμφανίζεται μενού που περιλαμβάνει στην κορυφή την επιλογή **Κενής Κάρτας** και από κάτω κατηγοριοποιημένα όλα τα έτοιμα σχολικά πρότυπα!
- **Διαδραστικές Γραμμές Σχέσεων (`+ Σχέση 🔗`):**
  - Κάντε κλικ στο κουμπί, επιλέξτε την κάρτα αφετηρίας και την κάρτα προορισμού. Δημιουργείται άμεσα γραμμή σύνδεσης με επεξεργάσιμη ετικέτα ρόλου.
- **Γραμμές Κληρονομικότητας (`+ Κληρονομικότητα 🧬`):**
  - Δημιουργεί γραμμή κληρονομικότητας με το επίσημο λευκό τρίγωνο UML `⮉`.
- **Διαγραφή Καρτών (`✕`):**
  - Διαγράφει την κάρτα και καθαρίζει αυτόματα όλες τις συνδεδεμένες γραμμές της.
- **Διαχείριση Ιδιοτήτων & Μεθόδων:**
  - Προσθήκη με τα κουμπιά `+Ιδ` / `+Μεθ` (ή πατώντας `Enter` μέσα σε υπάρχουσα γραμμή).
  - Διαγραφή μεμονωμένης γραμμής πατώντας το διακριτικό κουμπί `✕` (που εμφανίζεται στο hover) ή με `Backspace` σε κενή γραμμή.
- **Διαδραστικό Badge Σύνδεσης:**
  - Κάθε γραμμή διαθέτει badge στο μέσο της: επιτρέπει την εναλλαγή τύπου σχέσης (`🔗` ⇄ `🧬`), επεξεργασία κειμένου και διαγραφή γραμμής (`✕`).

## 11. Συχνές Ερωτήσεις & Επίλυση Προβλημάτων (FAQ)

### Ε: Πώς μπορώ να γράψω πάνω από ένα PDF ή μια παρουσίαση PowerPoint;
**Α:** Επιλέξτε κατάσταση **Επιφάνειας Εργασίας (Desktop)** από το μενού φόντου (`D`). Επιλέξτε το Μολύβι (`P`) ή τον Μαρκαδόρο (`H`) και σχεδιάστε απευθείας πάνω από το παράθυρο του PDF ή των διαφανειών. Όταν θέλετε να αλλάξετε σελίδα, πατήστε το πλήκτρο **`M`** (Mouse) για να αποκτήσετε ξανά πλήρη έλεγχο του ποντικιού.

### Ε: Πώς μπορώ να μετακινήσω έναν πίνακα ή ένα δένδρο στην οθόνη;
**Α:** Κάντε κλικ και σύρετε από τη σκούρα μπλε κεφαλίδα του πίνακα ή της δομής.

### Ε: Μπορώ να τρέξω την εφαρμογή σε σχολικό υπολογιστή χωρίς δικαιώματα διαχειριστή;
**Α:** Ναι! Χρησιμοποιήστε το εκτελέσιμο `myWhiteboard-Portable-1.1.2.exe`. Δεν απαιτεί εγκατάσταση, δεν γράφει στο μητρώο των Windows και τρέχει άμεσα ακόμα και απευθείας από USB stick.

### Ε: Πώς μπορώ να καθαρίσω γρήγορα όλες τις σημειώσεις χωρίς να χάσω τους πίνακες;
**Α:** Ανοίξτε το υπομενού της σβήστρας (`E`) και πατήστε **«Καθαρισμός Όλων»**. Όλες οι γραμμές του καμβά θα σβηστούν, ενώ οι πίνακες και τα διαγράμματα θα παραμείνουν άθικτα.

### Ε: Πού μπορώ να αναφέρω μια πρόταση βελτίωσης ή ένα σφάλμα;
**Α:** Μπορείτε να επικοινωνήσετε απευθείας μέσω email στο `pliroforikos@gmail.com` ή ανοίγοντας Issue στο GitHub repository: [github.com/pliroforikos/myWhiteboard](https://github.com/pliroforikos/myWhiteboard).
